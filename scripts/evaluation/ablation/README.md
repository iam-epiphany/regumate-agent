Entry-point feature gates cover batch/single reranking, table early returns,
structured retrieval, sibling/other evidence supplementation and citation scope
extension. Calculation-off keeps original operand/formula evidence, removes
computed-result evidence and deterministic answer shortcuts. Draft/validation
events snapshot values immediately, before downstream mutation. Synthetic
preflight checks disabled implementations without consulting formal questions.

Recursive and boundary-only indexes share parsed text, plain embedding inputs,
minimal metadata and length/overlap settings; both omit clause/cell indexes.
The boundary-only index splits identical raw text at matched heading/table
starts, then uses the same recursive splitter within each segment. It does not
rewrite table rows, insert summaries or add heading prefixes. Unmatched parser
blocks do not replace raw text. This isolates boundary constraints rather than
the production structural renderer; A2 includes that complete renderer.
Full clones all existing 46,556 vectors and the same 500-document SQL snapshot.
Content-addressed ASCII source paths preserve byte hashes and original parser
filenames. Qdrant collections are experiment-specific. SQLite workers use
`/ablation_runtime/<run>/...` in the isolated container, because Docker Desktop
bind mounts do not reliably support SQLite WAL locking. Completed index DBs are
backed up on Linux storage then exported to the host. Preserve the container for
resume; do not remove it. Production DB, collections and .env are untouched.

## Reproduction

From the repository in PowerShell, with production GPU use temporarily stopped
after snapshot initialization:

```powershell
python -m scripts.evaluation.ablation.run init --root data/ablation/<new-run>
python -m scripts.evaluation.ablation.run build --root data/ablation/<new-run>
python -m scripts.evaluation.ablation.preflight --help
# Capture environment/model manifests and all per-profile synthetic preflights.
python -m scripts.evaluation.ablation.execute --root data/ablation/<new-run>
```

`execute` runs identical synthetic API smoke questions, freezes required
artifacts/code/settings, runs 11 configurations in seeded random order, then
official 300 with default feature configuration. Requests are serial, question
order is fixed, and all workers prewarm the same CUDA models. An interrupted
dispatched question is a first-run failure, never silently retried. Errors and
missing outputs count as failures. No formal-set tuning is permitted. The
orchestrator restores the production container in its finally block.

Report paired gain/loss/net and 10,000-resample question-bootstrap intervals
(item sampling only, not model variability); one net correct answer equals 0.5
percentage points. Adjacent main rows are bundle effects, not independent
contributions. Module effects are conditional on Full. Negative/null effects
remain results. No historical score substitutes for this run.

`blind_review` hides profile/order and contains all substantive answers and
validation drafts, source excerpts and automatic prelabels. Human labels are
correct / omission / explicit error / insufficient evidence; critical facts
include numbers, units, subject, conditions, exceptions, time and negation.
Review all refusals for validity. Unresolved cases need human adjudication;
machine prelabels are never reported as completed human review or actual error
rates. The report leaves human-dependent metrics pending until review import.

Outputs: frozen protocol and hashes; append-only per-question journals/traces;
main and control paired results, eight question types, latency/calls/tokens;
blind packet and per-item differences; one-page defense summary. Official
default regression must be 300/300. Existing first artifacts must not be
overwritten; later diagnostics or regressions use separate paths.
