# 参考项目拆解与学习路线

本文档记录外部银行监管 RAG 项目的架构拆解与学习路线。

本项目只学习架构思想，不复制代码。

## 可学习的设计

- 后端服务分层清楚。
- 文档上传、处理、检索、回答各自独立。
- RAG 管线包含检索、rerank、引用和生成。
- 前端强调聊天体验、文档管理和引用展示。

## ReguMate 的简化

- 数据库先用 SQLite。
- 检索先用关键词。
- 回答先用模板。
- 不接入真实 LLM。
- 不接入向量数据库。
- 不做流式输出。

## 建议学习顺序

1. 当前关键词 RAG 数据流。
2. 文档解析和 chunk 策略。
3. 检索打分和拒答策略。
4. 引用结构与前端展示。
5. embedding 与向量检索。
6. rerank 和来源多样性。
7. 流式回答和引用校验。

每次升级前，先写清楚本项目的最小目标，再实现小步可验证版本。
