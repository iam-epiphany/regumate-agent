# 项目目录结构

本文档说明 ReguMate 可信 RAG、文档入库、表格证据检索与问答的目录边界。

```text
backend/
  main.py
  app/
    api/          # FastAPI router
    core/         # 配置、数据库连接等基础设施
    models/       # SQLAlchemy 数据库模型
    schemas/      # Pydantic API 契约
    services/     # 文档、chunk、RAG、表格检索和操作日志等业务逻辑
    tests/        # 后端 pytest
frontend/
  src/
    api/          # 前端 API client
    components/   # 通用组件
    pages/        # 问答、知识库、操作日志页面
    types/        # 前端类型
data/
  documents/
    originals/    # 上传原文，运行时数据
  regulations/    # 脱敏样例制度或填报说明
docs/
  开发文档/
```

## 后端边界

- `backend/main.py`：创建 FastAPI 应用、注册路由、托管前端构建产物。
- `api/`：处理 HTTP 请求、响应模型和异常转换。
- `schemas/`：定义 API 输入输出结构。
- `models/`：定义数据库表结构。
- `services/`：实现业务逻辑。
- `core/config.py`：应用名、数据目录、支持格式、chunk 大小等配置。
- `core/database.py`：SQLite engine、Session、建表入口。

## 前端边界

- `WorkspacePage`：状态概览和入口。
- `DocumentsPage`：上传文档、查看文档和 chunk。
- `RagPage`：输入问题、展示回答和引用。
- `AuditPage`：展示上传、问答和系统运行操作记录，不承载业务结论。

当前不新增独立业务审查目录、自动规则生成、替代人工签批、外部整改工单或消息通知目录。
