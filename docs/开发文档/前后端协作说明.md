# 前后端协作说明

ReguMate 当前采用前后端分离开发、生产构建后由 FastAPI 托管静态资源的方式。

## 后端

- FastAPI 应用入口：`backend/main.py`。
- API 前缀：`/api`。
- OpenAPI 文档：`/docs`。
- 数据库：`data/app.db`。
- 上传原文：`data/documents/originals/`。

## 前端

- Vite 应用目录：`frontend/`。
- 构建命令：`npm run build`。
- 构建产物：`frontend/dist/`。
- FastAPI 会在构建产物存在时托管根路径页面和 `/assets`。

## 联调流程

1. 后端启动后访问 `/api/health`。
2. 前端工作台调用健康检查。
3. 上传文档后，前端刷新文档列表。
4. 选择文档查看 chunk。
5. 问答页提交问题并展示回答与引用。
6. 审计页查看操作日志。

## 约束

- 前端不要硬编码未实现接口。
- 后端不要返回没有 schema 约束的临时结构。
- 修改 API 时同步更新 `API接口设计.md` 和 `V0接口文档.md`。
