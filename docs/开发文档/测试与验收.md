# 测试与验收

## 自动化测试

后端：

```powershell
.\.venv\Scripts\python.exe -m pytest
```

当前覆盖：

- 健康检查。
- 文档上传成功。
- 空文档返回 400。
- 文档列表和详情。
- 问答命中时返回 citations。
- 问答无命中时拒答。
- 审计日志记录上传和问答。

前端：

```powershell
cd frontend
npm run build
```

## 手动验收

1. 启动后端。
2. 打开 `http://127.0.0.1:8000/`。
3. 进入“知识库”，上传监管制度 `.txt`、`.md` 或 `.docx`。
4. 查看文档列表和 chunk 预览。
5. 进入“可信问答”，提问一个知识库中有依据的问题。
6. 检查回答是否带引用。
7. 提问一个无关问题，检查是否拒答。
8. 进入“审计日志”，检查上传和问答记录。
