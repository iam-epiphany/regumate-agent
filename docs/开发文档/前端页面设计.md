# 前端页面设计

ReguMate 前端是面向学习和演示的 RAG 工作台，不做营销首页。

## 页面结构

- 工作台 `/`：后端状态、知识库概览、最近操作、主功能入口。
- 知识库 `/documents`：上传文档、查看文档列表、预览 chunk。
- 可信问答 `/qa`：输入问题、展示回答、展示引用来源。
- 审计日志 `/audit`：查看上传、索引、问答记录。

## 交互原则

- 页面文案统一使用 ReguMate 和“可信 RAG 问答”主题。
- 上传入口只接受知识库文档。
- 问答页必须同时展示回答状态和引用来源。
- 无数据时给出清晰空状态。
- 前端不展示当前阶段未实现的旧业务入口。

## API 调用

- `src/api/documents.ts`：文档上传、列表、详情。
- `src/api/qa.ts`：可信问答。
- `src/api/audit.ts`：审计日志。
- `src/api/system.ts`：健康检查。

## 验收

运行：

```powershell
cd frontend
npm run build
```

构建通过即为当前前端基础验收。
