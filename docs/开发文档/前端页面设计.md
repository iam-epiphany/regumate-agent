# 前端页面设计

当前前端是 RAG-only 管理后台风格页面，不包含报表校验、异常详情和审查报告。

## 页面

| 路径 | 页面 | 用途 |
| --- | --- | --- |
| `/` | 工作台 | 查看后端状态、知识库概览、最近日志 |
| `/documents` | 文档知识库 | 上传监管文档、查看文档列表和 chunk |
| `/qa` | 可信问答 | 提问、展示回答、引用、拒答状态 |
| `/audit` | 审计日志 | 查看上传、入库、问答、拒答记录 |

## 设计原则

- 不做营销首页，第一屏就是工作台。
- 问答页必须展示引用来源。
- 拒答必须明显展示，不能伪装成普通回答。
- 前端类型集中在 `frontend/src/types/api.ts`。
- API 调用按领域拆分到 `frontend/src/api/`。
