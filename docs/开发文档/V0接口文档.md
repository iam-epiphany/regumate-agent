# V0 接口文档

本文记录 ReguMate 当前前后端稳定契约，统一前缀为 `/api`。完整字段说明见《API接口设计.md》。

## 文档接口

- `POST /documents/upload`：上传单份文档，可选 `metadata_json`；上传后异步解析、分块和索引。
- `POST /documents/batch-upload`：批量上传，返回逐文件状态。
- `GET /documents`：分页查询文档台账。
- `GET /documents/{document_id}`：查询文档、身份信息和分页 chunk。
- `GET /documents/{document_id}/processing`：查询持久化处理进度。
- `PATCH /documents/{document_id}/metadata`：部分更新身份字段。字段省略表示不修改，显式 `null` 表示人工置为未知。保存会撤销已有身份确认，并只刷新 SQLite/Qdrant metadata，不重新 embedding。
- `POST /documents/{document_id}/metadata/confirm`：确认当前身份快照；未知字段允许保留。响应包含 `identity_review_status`、`identity_reviewed_at` 和 `identity_reviewed_snapshot_hash`。
- `POST /documents/{document_id}/index`：显式重建索引。
- `DELETE /documents/{document_id}`、`POST /documents/bulk-delete`：删除文档、chunk 和对应向量。

身份字段包括标题、发文机关、文号、发布日期、生效/失效日期、版本状态、替代关系、来源 URL 和附件 URL。URL、manifest 和未知字段均不是确认门槛。系统不自动判断法律效力或版本替代关系。

## 问答接口

- `POST /qa/ask`：同步可信问答。
- `POST /qa/ask/stream`：SSE 流式问答。
- `POST /qa/tasks`：创建可恢复问答任务；通过 `/qa/tasks/{task_id}`、`/stream` 和 `/cancel` 查询、订阅或停止。

回答包含 `answer`、`answer_type`、`refused`、`refusal_code`、`citations`、`claims`、`evidence_coverage` 和 grounding 诊断。每个非拒答结论必须可回到真实文档证据；依据不足时返回结构化拒答，不允许以模型常识补齐。

## 健康与审计

- `GET /health/rag`、`GET /health/ready`、`POST /health/warmup`：检查 SQLite、Qdrant、Office 解析、模型文件、运行设备和队列。
- `GET /audit/logs`：查询用户可读事件；身份修改、清空、确认、撤销确认和版本关系变更均保留前后值与快照哈希。
- `/audit/archives`：查询或删除按日归档。

## 兼容约束

现有平铺 metadata 请求继续兼容。所有时间返回带时区 ISO 8601。新增字段保持可选，旧客户端忽略即可；前端必须把空值展示为“未知”，不得把未确认状态解释为元数据错误。
