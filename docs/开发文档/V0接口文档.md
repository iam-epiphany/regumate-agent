# V0 接口文档

本文档面向 ReguMate V0 演示和联调。

## GET /api/health

返回：

```json
{
  "status": "ok",
  "message": "ReguMate backend is healthy"
}
```

## POST /api/documents/upload

上传知识库文档。

请求：

- Content-Type: `multipart/form-data`
- 字段：`file`

返回：

```json
{
  "document_id": "DOC-20260707-0001",
  "filename": "reporting_rules.md",
  "content_type": "text/markdown",
  "size": 1024,
  "chunk_count": 3,
  "uploaded_at": "2026-07-07T10:00:00"
}
```

## GET /api/documents

返回文档摘要列表。

## GET /api/documents/{document_id}

返回指定文档详情和 chunk 预览。

## POST /api/qa/ask

请求：

```json
{
  "question": "资产合计应如何填报？"
}
```

返回：

```json
{
  "answer": "根据知识库中检索到的监管制度片段...",
  "citations": [
    {
      "document_id": "DOC-20260707-0001",
      "chunk_id": "DOC-20260707-0001-CHUNK-0001",
      "filename": "reporting_rules.md",
      "section_title": "资产合计",
      "page_number": null,
      "excerpt": "资产合计应等于各项资产分项金额合计。"
    }
  ],
  "confidence": 0.4,
  "refused": false
}
```

拒答时：

```json
{
  "answer": "知识库中未找到足够依据，无法给出确定回答。",
  "citations": [],
  "confidence": 0,
  "refused": true
}
```

## GET /api/audit/logs

返回上传、索引、问答等操作日志。
