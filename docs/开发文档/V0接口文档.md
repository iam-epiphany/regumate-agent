## POST /api/documents/upload

上传知识库文档。

请求：

- Content-Type: `multipart/form-data`
- 字段：`file`
- 文件会校验扩展名、MIME 类型和内容签名；伪装成 `.pdf` / `.docx` 的其他文件会返回 400。
- PDF 使用 loader adapter 解析：优先 PyMuPDF4LLM，候选 Docling / Unstructured，最终回退 pypdf；V0 不启用 OCR。
- 上传保存文件、解析文本、生成 chunk 并写入 SQLite，然后后台自动构建向量索引。接口会先返回上传结果，模型下载和 embedding 不阻塞用户上传响应。

返回：

```json
{
  "document_id": "DOC-20260707-0001",
  "filename": "reporting_rules.md",
  "content_type": "text/markdown",
  "size": 1024,
  "chunk_count": 3,
  "uploaded_at": "2026-07-07T10:00:00"
}
```

## GET /api/documents

返回文档摘要列表。

列表接口会检查 `data/documents/originals/` 中的原始文件是否仍存在。若 SQLite 元数据缺失但 `DOC-*` 原始文件仍在，系统会尝试恢复 document/chunk 记录；若 Qdrant 向量数量完整，恢复后状态为 `indexed`，否则为 `uploaded` 并等待重建索引。

若 SQLite 记录指向的原始文件被外部删除，接口不会自动删除数据库或 Qdrant 记录，而是将文档标记为 `source_missing`，暂停参与问答；用户可恢复原始文件或显式调用删除接口。

文档状态：

- `uploaded`：文档已上传并切分 chunk，但尚未写入向量索引。
- `indexing`：SQLite 已保存，正在写入向量索引。
- `indexed`：向量索引可用。
- `index_failed`：向量索引失败，可查看 `index_error` 并运行重建脚本修复。
- `source_missing`：SQLite 记录存在，但原始文件缺失；该文档暂停参与问答。
- `deleting`：正在删除 Qdrant 向量、原始文件和 SQLite 记录。
- `delete_failed`：Qdrant 向量删除失败，文档记录仍保留，可重试删除。

## POST /api/documents/{document_id}/index

为指定文档手动重建向量索引。正常上传流程会自动触发后台索引；该接口主要用于修复 `index_failed` 或重建旧数据。

成功时返回文档详情，状态为 `indexed`。失败时返回 503，并将文档状态更新为 `index_failed`。

## GET /api/documents/{document_id}

返回指定文档详情和 chunk 预览。chunk 会尽量保留结构化解析得到的章节标题和页码。

若原始文件已被外部删除，详情接口会将文档标记为 `source_missing` 并返回该文档详情，不会自动清理 SQLite 或 Qdrant。

chunk 字段包括：

```json
{
  "chunk_id": "DOC-20260708-0001-CHUNK-0003",
  "text": "完整 chunk 文本；表格会转换为行级自然语言证据",
  "text_preview": "完整 chunk 文本；表格会转换为行级自然语言证据",
  "chunk_type": "paragraph",
  "is_truncated": false,
  "section_title": "2. 普惠小微贷款统计口径",
  "page_number": null,
  "token_count": 216,
  "index_status": "indexed",
  "index_version": "bge-m3-qdrant-v1",
  "created_at": "2026-07-08T12:00:00+00:00"
}
```

`text_preview` 只是摘要；前端查看 chunk 时应使用 `text`。
表格不会整表原样入库，而是按行转成自然语言证据。

## DELETE /api/documents/{document_id}

删除指定文档。后端会先删除 Qdrant 向量；只有向量清理成功后，才会删除原始文件、SQLite 文档和 chunk 记录。

返回：

```json
{
  "document_id": "DOC-20260708-0001",
  "deleted": true,
  "vector_warning": null
}
```

如果文档正在构建向量索引，返回 409。若 Qdrant 删除失败，返回 503，文档状态会变为 `delete_failed`，`index_error` 中保留失败原因，用户可稍后再次调用删除接口重试。

## POST /api/qa/ask

请求：

```json
{
  "question": "资产合计应如何填报？"
}
```

返回：

```json
{
  "answer": null,
  "citations": [
    {
      "document_id": "DOC-20260707-0001",
      "chunk_id": "DOC-20260707-0001-CHUNK-0001",
      "filename": "reporting_rules.md",
      "section_title": "资产合计",
      "section_path": ["资产合计"],
      "section_number": null,
      "parent_section_number": null,
      "previous_chunk_id": null,
      "next_chunk_id": null,
      "page_number": null,
      "excerpt": "资产合计应等于各项资产分项金额合计。",
      "score": 0.7,
      "rerank_score": 0.9,
      "chunk_type": "paragraph",
      "evidence_role": "direct_evidence"
    }
  ],
  "confidence": 0.85,
  "refused": false
}
```

`confidence` 是证据强度校准值，不直接展示为 reranker 原始百分比。前端按证据强/中/弱展示。当前 V0 不生成最终自然语言答案；若 `retrieval_summary.has_sufficient_context=false` 或 `missing_aspects` 非空，后续 LLM 应说明依据不足。引用 `excerpt` 最长约 1200 字，以便保留完整证据窗口。工程编号保留在引用详情中。

拒答时：

```json
{
  "answer": null,
  "citations": [],
  "confidence": 0,
  "refused": true,
  "context_package": {
    "retrieval_summary": {
      "has_sufficient_context": false,
      "coverage_notes": [],
      "missing_aspects": ["未召回可用知识片段"],
      "query_count": 0,
      "candidate_count": 0,
      "reranked_count": 0,
      "filtered_count": 0,
      "timings_ms": {},
      "score_range": {}
    }
  }
}
```

检索系统不可用时：

```json
{
  "detail": "Qdrant hybrid 检索失败"
}
```

状态码为 `503`。

## GET /api/audit/logs

返回当天上传、索引、问答等操作日志。调用该接口时，今天之前的日志会自动按日期归档到 `data/audit_archives/audit-YYYY-MM-DD.md`，并从 SQLite 中移除。

问答日志的 `detail` 是 JSON 字符串，包含：

```json
{
  "question": "资产合计应如何填报？",
  "answer": null,
  "is_final_answer": false,
  "mode": "rag_context",
  "used_chunks": 1,
  "refused": false,
  "confidence": 0.85
}
```

问答审计不保存引用来源，引用仍以问答响应为准。

## GET /api/audit/archives

返回历史日志归档文件列表。

```json
{
  "archives": [
    {
      "date": "2026-07-07",
      "filename": "audit-2026-07-07.md",
      "size": 2048,
      "updated_at": "2026-07-08T00:01:00+00:00"
    }
  ]
}
```

## GET /api/audit/archives/{archive_date}

查看某一天归档文件的 Markdown 内容，`archive_date` 格式为 `YYYY-MM-DD`。

## DELETE /api/audit/archives/{archive_date}

删除某一天归档文件。删除后该天历史日志不再显示。
## RAG 健康检查

### `GET /api/health/rag`

返回模型离线加载和 Qdrant 连接状态。该接口不主动加载大模型，模型缺失时不会抛 500，而是在响应中返回 `*_model_ready=false` 和中文错误信息。

```json
{
  "offline_mode": true,
  "embedding_model_ready": true,
  "reranker_model_ready": true,
  "embedding_model_path": "/app/data/models/bge-m3",
  "reranker_model_path": "/app/data/models/bge-reranker-v2-m3",
  "qdrant_ready": true,
  "embedding_model_error": null,
  "reranker_model_error": null,
  "qdrant_error": null
}
```
