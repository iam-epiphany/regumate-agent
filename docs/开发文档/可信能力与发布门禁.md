# 可信能力与发布门禁

## 当前实现边界

ReguMate 以冻结 500 份官方文档为知识来源，回答必须绑定真实文档、chunk、页码、工作表或单元格；无依据时拒答。官网 URL、附件 URL 和来源 manifest 均为可选字段，不是身份确认或发布门槛。

文档身份可信链允许未知值和可选人工确认。系统不根据文件名、日期或正文偶然出现的日期自动断言法规效力，也不自动建立替代关系。身份确认只证明人工核对了某一版身份快照，不代表法律效力认证。

## 100 题挑战协议

- 题集：30 道中等、70 道困难；40 道开发集、60 道封存集；覆盖事实、语义、表格、计算、跨文件、制度与报表联合、公式、版本和拒答。
- 隔离：`questions.jsonl` 仅含在线运行所需问题；`gold.jsonl` 仅供离线评分器读取，禁止进入应用知识库；`lock.json` 绑定题集、金标、500 文档快照、评测相关代码和评测器哈希。
- 复核：状态为 `codex_verified`，采用生成检查、脱离答案复核证据、程序化一致性校验；未经过银行监管专家人工复核，封存集不是第三方独立盲测。
- 原始性：在线 HTTP 响应、引用、claims、trace、耗时和错误原样保存，评分器不把系统返回的 `grounding.passed` 当作答案正确性。

## 发布门槛和当前结论

当前质量发布门槛优先检查正确率、引用真实性、拒答准确率和可审计性：请求必须完成且程序错误为 0；官方 300 必须保持 300/300；内部困难集 holdout 至少满足 overall、answerable、refusal 均不低于 90%，且无无效引用和明显证据回退。运行时间继续记录 P50/P95/最大值，但按 2026-07-24 目标调整，当前不作为硬性阶段门槛；待正确率和可信指标稳定后，再单独恢复性能优化门禁。

首次封存运行完成 60/60 个请求且程序错误为 0，但仅答对 42/60，未达到质量门；该历史失败必须保留。2026-07-24 Stage 5 当前回归在同一内部 holdout 上达到 57/60、overall 95.00%、answerable 93.33%、refusal 100%、`gate_passed=true`，并且官方 300 为 300/300。该成绩只能称为内部封存困难集回归结果，未经过银行监管专家人工复核，也不是第三方独立盲测。

## 工具入口

- `scripts/build_trust_challenge_100.py`：从官方文档证据生成并结构校验挑战集。
- `scripts/run_trust_challenge.py`：只读取问题文件并保存原始响应。
- `scripts/evaluate_trust_challenge.py`：离线读取金标，按题型和独立证据评分。
- `scripts/freeze_trust_challenge.py`：生成语料、题集、代码和评测器锁定哈希。
- `scripts/backfill_document_identity.py`：幂等回填 500 文档身份并输出审计。
- `scripts/run_release_validation.ps1`：验证已封存产物，不覆盖首次封存结果。
