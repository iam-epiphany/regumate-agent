# 项目目录结构

本文档说明 ReguMate 当前 RAG-only MVP 的目录边界。

```text
backend/
  main.py
  app/
    api/          # FastAPI router
    core/         # 配置、数据库连接等基础设施
    models/       # SQLAlchemy 数据库模型
    schemas/      # Pydantic API 契约
    services/     # 文档、chunk、RAG、审计等业务逻辑
    tests/        # 后端 pytest
frontend/
  src/
    api/          # 前端 API client
    components/   # 通用组件
    pages/        # 工作台、知识库、问答、审计页面
    types/        # 前端类型
data/
  documents/
    originals/    # 上传原文，运行时数据
  regulations/    # 脱敏样例制度或填报说明
docs/
  开发文档/
```

## 后端边界

- `backend/main.py`：创建 FastAPI 应用、注册路由、托管前端构建产物。
- `api/`：处理 HTTP 请求、响应模型和异常转换。
- `schemas/`：定义 API 输入输出结构。
- `models/`：定义数据库表结构。
- `services/`：实现业务逻辑。
- `core/config.py`：应用名、数据目录、支持格式、chunk 大小等配置。
- `core/database.py`：SQLite engine、Session、建表入口。

## 前端边界

- `WorkspacePage`：状态概览和入口。
- `DocumentsPage`：上传文档、查看文档和 chunk。
- `RagPage`：输入问题、展示回答和引用。
- `AuditPage`：展示上传和问答审计记录。

## 不保留的目录

当前不新增真实报表文件校验、规则引擎、人工复核、审查报告等目录。后续若进入新阶段，需要先更新 `AGENTS.md` 和项目计划。
