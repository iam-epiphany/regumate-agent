# 项目目录结构

本文档说明 ReguMate 可信 RAG 与业务报表审查的目录边界。

```text
backend/
  main.py
  app/
    api/          # FastAPI router
    core/         # 配置、数据库连接等基础设施
    models/       # SQLAlchemy 数据库模型
    schemas/      # Pydantic API 契约
    services/     # 文档、chunk、RAG、规则审查、复核和操作日志等业务逻辑
    tests/        # 后端 pytest
frontend/
  src/
    api/          # 前端 API client
    components/   # 通用组件
    pages/        # 问答、知识库、业务审查、操作日志页面
    types/        # 前端类型
data/
  documents/
    originals/    # 上传原文，运行时数据
  regulations/    # 脱敏样例制度或填报说明
docs/
  开发文档/
```

## 后端边界

- `backend/main.py`：创建 FastAPI 应用、注册路由、托管前端构建产物。
- `api/`：处理 HTTP 请求、响应模型和异常转换。
- `schemas/`：定义 API 输入输出结构。
- `models/`：定义数据库表结构。
- `services/`：实现业务逻辑。
- `core/config.py`：应用名、数据目录、支持格式、chunk 大小等配置。
- `core/database.py`：SQLite engine、Session、建表入口。

## 前端边界

- `WorkspacePage`：状态概览和入口。
- `DocumentsPage`：上传文档、查看文档和 chunk。
- `RagPage`：输入问题、展示回答和引用。
- `ReviewPage`：配置有监管依据的规则、执行报表审查、复核发现并导出报告。
- `AuditPage`：展示上传、问答和审查任务的系统操作记录，不承载业务结论。

## 业务审查目录

- `models/review.py`：规则、持久化审查任务和发现项。
- `schemas/review.py`：规则配置、任务、发现和报告 API 契约。
- `services/report_review_service.py`：确定性规则执行、人工复核和报告生成。
- `services/report_review_task_service.py`：有界异步队列与重启恢复。
- `api/review.py`：业务审查 HTTP 路由。

仍不新增自动规则生成、替代人工签批、外部整改工单或消息通知目录。
