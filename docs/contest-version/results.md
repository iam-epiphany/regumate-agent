## 7. 已知限制

- 表格问题若同一工作表内存在多个同名行板块，用户未给出工作表、机构或口径时，系统会拒绝猜测；本组表格用例给出了工作表或明确指标，属于可复核路径。
- 语义核验由在线模型完成，可能出现传输失败、输出截断或服务不可用；系统分别显示服务异常或校验失败，不会转写为“证据不足”。本版对核验步骤默认关闭思维输出，仅用于降低短 JSON 被截断的风险。
- 本组结果来自单机 GPU 环境和当前知识库，不是对全部监管资料的泛化评测。
