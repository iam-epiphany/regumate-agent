# 关键指标总结：官方 300 题与自命题 200 题（准确率 + CPU/GPU 性能实测）

**日期：** 2026-08-05
**用途：** 供比赛测试报告引用——正确率、CPU/GPU 处理时间、证据与拒答等关键指标。
**数据来源：** 历史评测产物（`docs/evaluation/`、`data/evaluation/`）+ 本次新增实测（CPU/GPU 各一轮）。

---

## 1. 测试环境

| 项目 | 配置 |
|---|---|
| CPU | AMD Ryzen 9 8945HX（16 核/32 线程），内存约 34 GB |
| GPU | NVIDIA GeForce RTX 5070 Laptop，8 GB 显存（实测 CUDA 可用） |
| 运行方式 | Docker 容器 `regumate/app:contest-v3`（build_id `regumate-agent-small`），torch `2.11.0+cu128` |
| 模型 | BGE-M3（embedding）+ BGE-reranker-v2-m3（重排），进程内单例；生成用 DeepSeek API（deepseek-v4-flash） |
| 知识库 | 500 份文件（doc 32 / docx 34 / pdf 45 / xls 232 / xlsx 157），SQLite 46,551 chunks + 133,001 表格单元，Qdrant 45,530 向量 |
| CPU 模式 | 容器内无 CUDA 时按 `MODEL_DEVICE=cuda` 请求自动回退 → `cpu_balanced`（16 线程） |
| GPU 模式 | `--gpus all` 启动，`selected_device=cuda`，`performance_mode=gpu` |

> 说明：同一镜像、同一代码、同一知识库下仅设备不同。CPU/GPU 两组开放题评测均**串行**单请求执行，0 运行错误。

## 2. 官方 300 题（选择题，`data/contest_dataset/QA数据.xlsx`）

### 2.1 准确率

**300/300 = 100%，0 运行错误**——本次 CPU、GPU 两轮实测均为 300/300，与历史多次回归（7-31 至 8-05 共 10+ 轮）一致。

### 2.2 处理时间（单轮问答，串行）

| 环境 | 平均 | P50 | P95 | 最大 |

| GPU（历史回归 2026-08-03，多次） | 0.85–1.46 s | 0.37–0.93 s | — | 12.5–18.3 s |

**解读：** 选择题大部分走确定性表格链路（Excel 类 ~0.2–0.4 s，CPU/GPU 几乎无差，P50 均为 ~0.2 s）；文本类含 LLM 生成，GPU 平均提速约 **13 倍**（7.03 s → 0.54 s），P95 提速约 9 倍。

## 3. 自命题 200 题（去锚 100 题 + 去锚 100 题 B，开放问答）

### 3.1 准确率（确定性评分器，金标逐事实比对）

| 批次 | CPU（2026-08-05 最终验收） | GPU（2026-08-05 本次实测） |
|---|---:|---:|
| 旧 100 题 | 90/100 | 88/100 |
| 新 100 题 | 93/100 | 92/100 |
| **合计** | **183/200 = 91.5%** | **180/200 = 90.0%** |

> 两轮均 0 运行错误。GPU 与 CPU 差 3 题，处于系统已记录的同代码重复运行波动区间（±1–3 题，由 LLM 生成随机性引起），非设备差异；表格类、拒答类两轮完全一致（见 3.3）。

### 3.2 处理时间（单轮问答，串行）

| 批次 | CPU avg / p50 / max | GPU avg / p50 / max |
|---|---:|---:|
| 旧 100 题 | 25.5 / 28.2 / 88.5 s | 17.1 / 13.6 / 99.5 s |
| 新 100 题 | 31.3 / 31.8 / 134.6 s | 18.7 / 14.5 / 168.8 s |
| **合计 200 题** | **28.4 / 29.8 / 134.6 s** | **17.9 / 14.1 / 168.8 s** |
| （历史参考 8-04 串行） | 旧 30.8 / 34.3 / 125.7 s；新 34.5 / 35.0 / 180.0 s | — |

**解读：** 开放题延迟由 DeepSeek API 生成（约 10–12 s/题）主导，GPU 将本地检索+重排从 ~15 s 压到 ~3 s，故：
- 平均提速约 **1.6 倍**（28.4 → 17.9 s），P50 提速约 **2.1 倍**（29.8 → 14.1 s）；
- 长尾 max 为 LLM API 偶发慢响应（CPU/GPU 两轮均存在，最大 134–169 s），非本地计算瓶颈；
- 拒答类与表格类确定性链路毫秒级返回（~10–70 ms），CPU/GPU 无差。

## 7. 结论摘要

1. **官方 300 题：正确率 300/300（100%），0 错误**；GPU 平均 0.54 s（P50 0.22 s），CPU 平均 7.03 s（P50 0.26 s）。
2. **自命题 200 题：CPU 183/200（91.5%）、GPU 180/200（90.0%）**，0 运行错误；表格类 40/40、拒答 40/40 两种设备下均 100%。
3. **时间：开放题 GPU 平均 17.9 s / P50 14.1 s，CPU 平均 28.4 s / P50 29.8 s**；GPU 平均提速 1.6 倍、P50 提速 2.1 倍（受 LLM API 延迟约 10–12 s 地板限制，非 3 倍级提速）。
4. **证据引用命中率 91.3–91.9%，拒答率 100%，实体错误率 2.4%**——均在赛题达标线上（≥90% / ≥80% / ≤5%）。
5. 两轮准确率差 3 题属于 LLM 运行波动区间，设备本身不改变正确率结果。
