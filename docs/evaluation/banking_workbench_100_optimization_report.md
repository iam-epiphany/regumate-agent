## 3. 本轮修复内容(3 项)

### ① 拒答边界(workbench +6,官方 300 不回归)

新增 `_explicit_request_boundary_code` 前置边界识别,三类触发:
- **预测请求** → `unsupported_prediction`(请预测/预计/明年/下一季度/走势预测…)
- **主观业务决策** → `subjective_business_advice`(应否/是否应当/是否应上调/替我决定…)
- **超资料库范围** → `out_of_scope_or_realtime`(某银行年报/内部资料/LPR报价/定期存款利率…)

两处防误伤(实测修正):
- **银行名需搭配数据请求词**:单独出现银行名(如名单判断题引用"中国建设银行股份有限公司")不触发;须同时出现"年报/净利润/不良贷款率"等数据请求词才拒答
- **"预计"会计术语保护**:"预计负债/预计净残值/预计使用寿命"不判为预测

标记词集全量验证:1346+600 官方题 **84 触发、0 误伤**(否决了 codex 原标记中的"推断"12FP/"估计"6FP/"未来"1FP);补充内联选项防护(选项文本中的"未说明"等不触发)。

### ② 表格复合定位(表格取数 +2,表格计算 +1)

- `COMMON_TABLE_INDICATORS` 增加资金运用表资产类行项(银行存款/债券/股票/证券投资基金/长期股权投资等)
- 引号内测量范围词(本年累计/截至当期/账面余额/规模占比等)不再误作指标
- calculate 任务移除全局列过滤(操作数自带列,全局过滤会先丢弃操作数);selector 显式列优先于问题推导列

### ③ extractive 降级改结构化拒答

开放题长答案校验失败时不再降级为"无结论摘录"(读起来像拒答却不说明),改为明确结构化拒答 `validation_failed_no_reliable_answer`。
