## 2. 六类错因(按可修复价值排序)

### ① extractive_fallback 降级无结论(25 题)——最大损失群

LLM 生成校验失败后降级为摘录,**摘录对验证题无结论价值**(没有"说法正确/错误"判断),judge 一律判错。

- 保险集团偿付能力报告"名单题"9 题(Q214/220/226/232/238/244/286/292/298):金标"X 公司属于应当编报报告的保险控股型集团",材料为名单;生成校验失败降级。
- 其他单事实 6 题(Q138/186/216/235/285/294)。
- 多事实 10 题(Q109/118/130/142/157/172/196/233/248/296):需逐项判断两项表述并分别引用,长答案校验失败;其中 4 题残留"生成服务暂不可用"(LLM 调用仍失败,Q118/142/233/248/296)。
- 需要进一步定位:每题的**校验失败字段**(引用/实体/覆盖)——从 `context_package` 的 grounding 或对单题重跑诊断。

### ② 验证标准过严(6 题,llm_grounded)——语义等价判定缺失

系统把"表述与材料用词略有差异/省略修饰"判为"说法错误/不完整",而金标(官方正确选项)判定为"属于材料内容":

| 题 | 系统判错理由 | 金标语义 |
|---|---|---|
| Q104 | "经监管认定" ≠ "经国家金融监督管理总局认定" | 简称与全称等价 |
| Q161 | 表述遗漏"不得形成赎回预期"要件 | 表述本身是材料内容 |
| Q182 | 表述省略"对多个银行保险机构…"条件 | 同上 |
| Q213 | "0年到20年" ≠ "0<t≤20" | 区间语义一致 |
| Q234 | "鼓励" ≠ "指导" | 官方认可的表述 |

**根因**:验证题的判定契约是"表述是否符合材料内容",系统按"表述是否与材料逐字一致/无遗漏"执行。官方金标语义是"表述的核心事实存在于材料(或为官方认可表述)"。需要 prompt 级修复:**只有核心事实(主体/行为/客体/数量/条件)与材料矛盾时才判错误;同义简称、限定词省略、表述详略差异应判正确**。

### ③ 结构化拒答误伤(4 题)——分诊判定与检索覆盖不一致

Q237/243/273:检索端 `covered_aspects=['document_anchor_1']`(上下文覆盖),但生成端 claim 未标注该 aspect → 分诊判定 `missing_required_aspect_ids=['document_anchor_1']` → 结构化拒答。**检索证据存在,LLM 生成未按要求标注 aspect_ids**——这是 LLM 标注质量问题被分诊放大为拒答。

Q263:2 个 aspect 均检索覆盖,`document_anchor_2` 的 claim 未标注 → 拒答。

修复方向:aspect-only 分诊应只在**检索端也未覆盖**时触发;若检索覆盖但 claim 未标注,说明 LLM 未遵循"每方面至少一条 claim"指令,应走 repair 轮(内容类问题)而非确定性拒答。

### ④ 表格比较数值口径(5-6 题)——金标区间修复已覆盖

Q036/37/38/41/43:题面未指定期间,系统取第一个匹配期间值(如一季度 8017.85),金标原为跨期间 max。**已修复**:金标新增 `expected_value_range`(该指标在题面口径下所有期间的值域),judge 按区间判定。Q042 系统值 66289 不在区间内(系统取数口径问题,待查)。

### ⑤ 官方口径差异(3 题,不可修复)——题目本身的问题

Q045/53/61:候选含"总资产"(35万亿),独立数值最大为总资产,官方金标为"原保险保费收入"。系统按数值最大答"总资产"→ 判错。**这是官方出题口径缺陷**(已在金标 `gold_remarks` 记录),与系统能力无关;系统行为(数值最大)是正确解读,无法在不违反官方判定下修复。

### ⑥ judge 自身问题(2-4 题)

Q059/66:`judge_error: Extra data`(DeepSeek 评审输出多余内容导致 JSON 解析失败),重跑可恢复;另有 5 题低置信评审需人工复核。judge 对文本题判定存在波动(基线 r1/r2 对比:单事实 110 vs 104),评审稳定性需改进(如评审两次取一致)。
