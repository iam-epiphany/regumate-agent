# 去锚100题B 错题根因修复说明（2026-08-04）

依据首跑盲测 83/100（合并回归 87/100，未达第一批 92/100 验收线）的 17 道错题根因分析，对生产代码实施 5 项通用修复 + 1 项环境修复。**修复后尚未重新评测**（按任务要求，先修复不测试；评测需先重建容器镜像）。

## 修复项

### 1. 拒答边界泛化（对应错题 F06/F09/F10/F19）
`backend/app/services/rag_service.py`
- `_OUT_OF_CORPUS_MARKERS` 增加 `"LPR"`（贷款市场报价利率实时报价请求；语料中 LPR 出现 0 次、官方题库 0 次，无合法题误伤）、`"存款挂牌利率"`（F10 题面含"挂牌"二字，原"定期存款利率"子串不匹配）
- `_OUT_OF_CORPUS_DATA_REQUESTS` 增加 `"拨备覆盖率"`（仅与 `_OUT_OF_CORPUS_BANK_NAMES` 共现时触发，行业口径问题不受影响——已验证"农村商业银行拨备覆盖率"不触发）
- "评估…可行性"正则由 `评估[^，。；]{0,14}可行性` 放宽为 `{0,24}`（F19"评估某信托公司收购一家不良资产平台的可行性"中间 19 字符；"可行性分析"、"可行性评估"等合法表述不受影响，已验证 Q179 选项题不误伤）

### 2. 降级链修正：中性前缀 + 证据受限二次生成（对应错题 D03/D11/R05/R09/X01/X04 等）
`backend/app/services/answer_generation_service.py`、`backend/app/services/prompt_builder.py`
- extractive 降级前缀由"已检索到相关依据，但生成答案未通过事实校验。为避免不可靠表述，先返回可核验摘录：/生成服务暂不可用。根据当前最相关证据："统一改为中性"根据当前检索到的依据，相关要点如下："——恢复路径信息保留在 `degraded`/`generation_status` 诊断字段中，答案文本不再渲染失败感，评分可匹配摘录中的结论句
- 新增 `_evidence_bound_regeneration`：开放问答在「模型拒答」「修复轮仍拒答」「修复轮校验仍失败」三处，各追加一轮证据受限生成（prompt 指令：仅使用知识片段原文组句、直接给出结论、证据不足才拒答）；该轮通过校验即返回，否则回退原 extractive 恢复/结构化拒答

### 3. LLM 调用容错（对应瞬时失败 D05/D10/R08/R19）
`backend/app/services/answer_generation_service.py`
- `_call_llm` 异常分支：总预算剩余 >15s 时 sleep 1s 后继续下一轮尝试（不再因非 stream 最后一次失败直接降级），瞬时连接故障可自愈；预算耗尽才 raise 进入 extractive 兜底

### 4. 检索 prompt 选择增强（对应错题 D03/D11/T08/X04）
`backend/app/services/rag_service.py`
- 新增 `_evidence_fit_bonus`：generic 邻居选择阶段，对「定义型问题（含定义/如何界定/是什么等）× 证据含定义句式（所称/是指…）」加 0.2 排序分；对问题提到的机构/方法限定词（财产保险公司/内部评级法/第三档等）与证据共现每项加 0.1 分——仅在同等分数下打破平局，不绕过 `_passes_prompt_score` 阈值

### 5. 表格计算操作数定位（对应错题 TC2）
`backend/app/services/query_planner_service.py`
- `_institution_row_terms`：机构词清洗新增"取最后一个连词之后的部分"——修复"保险公司资金运用余额**与**财产险公司…"中把指标词残片"余额与"吞进机构名（伪词"余额与财产险公司"）的问题；机构名本身不含连词，通用安全
- 验证：TC2 操作数解析为 [保险公司 资金运用余额, 财产险公司 资金运用余额]，表格检索 valid_calculation，计算 332580.2226 − 22206.00422 = 310374.21838（与金标一致）；跨表/季度/比例题型回归全部通过
