# 给 Codex 的阶段提示词：Round 1

请执行第一批全新100题的生成、审计、冻结、首次盲测、通用归因和修复。

开始时读取 `AGENTS.md`、`STATE.json`、Phase 2交接文件和 `PROTOCOL.md` 第5—13节。先运行完整质量门禁，官方300题必须300/300。

要求：

1. 从完整官方500文档语料池生成100道合理银行业务问题：80可答、20拒答/澄清，参考官方300题难度，可略高但不得为难而难。
2. 满足题型、难度、文档覆盖和严格“全新题目”定义；不得仅改写历史题。
3. 独立审计所有题目；程序验证表格、公式、数字、单位、版本、证据和拒答边界；失败题自动替换，冻结前保证100道有效题。
4. 将公开题和私有金标隔离；冻结questions、gold哈希、scorer、语料和代码快照。
5. runner只读公开题，保存Round 1首次盲测原始结果；scorer独立评分并封存报告。
6. 优化阶段只读取安全诊断包，按通用失败类别修复。禁止读取私有gold，禁止case专用补丁。
7. Round 1失败题只用于回归，不得把修复后的同轮分数称为首次盲测。
8. 每次有效提交前官方300必须300/300，并运行反硬编码、工程和冻结门禁。
9. 更新STATE和 `round_01_*.md` 交接文件，保存首次结果、修复后回归和所有commit。

结束时明确区分“Round 1首次盲测”与“Round 1修复后回归”。
