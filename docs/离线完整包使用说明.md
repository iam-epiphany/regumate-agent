# ReguMate 完整部署包入口

完整操作说明见同目录的 `比赛平台部署文档.md`。最终 ZIP 根目录同时提供 `DEPLOYMENT.pdf`、`DEPLOYMENT.md`、`.env`、linux/amd64 镜像及本地模型。

Linux 从解压后的项目根目录执行 `sh scripts/offline/start.sh`，GPU 加 `--gpu`。Windows 使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\offline\start.ps1`，GPU 加 `-Gpu`。

真实 API Key 按项目所有者授权仅存放于随包根目录 `.env`。默认 `MODEL_DEVICE=cpu`、`SERVICE_PORT=8000`、`REGUMATE_BIND_ADDRESS=0.0.0.0`。部署不下载模型和依赖，完整答案生成仍需要 `.env` 指向的国产大模型接口可达且有可用额度。

使用 `python scripts/offline/verify.py --base-url http://127.0.0.1:8000` 复核部署；实际交付验收记录见包内 `ACCEPTANCE_REPORT.md`。不要使用历史源码打包入口代替本完整包。

重新打包需在源项目准备好全部模型、资料、已索引知识库及应用镜像，先生成 `output/pdf/ReguMate-Deployment-20261022.pdf`，然后执行 `python scripts/build_offline_delivery.py --output dist-delivery/ReguMate-Agent-Submission-20261022 --app-image regumate/app:submission-20261022-amd64`。脚本会短暂停止源应用写入以捕获一致数据库快照，随后恢复源应用。输出目录必须不存在。
