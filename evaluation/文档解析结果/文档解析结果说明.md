# 文档解析结果说明（结构化知识库）

## 1. 知识库规模（2026-08-05 实测，运行时数据库 `data/evaluation/final_runtime`）

| 项目 | 数量 |
|---|---:|
| 制度/附件文件 | **500 份**（.doc 32 / .docx 34 / .pdf 45 / .xls 232 / .xlsx 157） |
| 解析成功 | 500/500（0 失败、0 降级） |
| 文本/表格 chunk | 46,551 条（含文档结构元数据：章节号、条款号、前后邻接） |
| 表格单元（结构化单元格） | 133,001 个（带 sheet、坐标、行/列标签、单位、数值） |
| 向量索引 | 45,530 条（Qdrant，混合检索：稠密 + 稀疏 + 关键词） |

## 2. 解析方式（按文件类型）

| 格式 | 解析器 | 输出 |
|---|---|---|
| .doc | LibreOffice 转换 + 结构抽取 | 段落/标题层级、条款号元数据 |
| .docx | python-docx | 段落/表格、章节结构 |
| .pdf | pymupdf4llm | 按版式抽取文本段落 |
| .xls | xlrd / LibreOffice | sheet → 结构化单元格（行/列标签 + 数值 + 单位） |
| .xlsx | openpyxl | sheet → 结构化单元格 |

## 3. 溯源信息（manifest）

每个入库文件在 `evaluation/文档解析结果/ingest_manifest.json`（500 条）与 `evaluation/文档解析结果/parse_manifest.json`
中记录：`doc_id`、标题、本地路径、文件大小、SHA-256、文件类型、解析结果
（chunk/cell 数）等，便于溯源、去重与版本管理（来源 URL 按参赛要求忽略）。

## 4. 重建方法（复现实验脚本）

解析与索引完全可复现，重建命令：

```bash
# ① 准备 500 份语料（data/contest_dataset/dataset/nfra_page_attachments_500）
scripts/prepare_contest_data.ps1        # 幂等准备数据目录
# ② 一键入库（解析 + 切分 + 向量化 + 单元格索引）
scripts/ingest_contest_dataset.py       # 或 PowerShell 包装 upload_contest_knowledge_base.ps1
# ③ 可选：单独重建向量索引 / 单元格索引
scripts/rebuild_vector_index.py
scripts/rebuild_spreadsheet_cell_index.py
# ④ 校验解析完整性
scripts/evaluate_ingestion.py           # 生成 ingestion_metrics.json（与上方规模数据对应）
```

> 提交包不含运行时数据库（SQLite/Qdrant 体积大），评审环境按上述命令重建即可
> 获得与评测一致的 500 份文件知识库（重建产物与官方 300 题回归、自命题 200 题
> 评测结果一一对应，见《关键指标总结》与测评报告）。

## 5. 证据返回粒度

检索链路支持条款级（条款号/章节元数据 + 定义条款定位）、段落级（文本 chunk）、
表格单元级（单元格证据）三种粒度，回答引用中逐条标注 `chunk_id` 与来源文件。
