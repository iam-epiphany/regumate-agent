# ReguMate 可信 RAG 问答系统 —— 测试报告

**赛题：** 面向银行业监管制度与统计报表的可信 RAG 问答（南京银行，揭榜挂帅赛道）

---

## 1. 测试概述

### 1.1 测试目的

围绕赛题量化指标与系统能力指标，对系统进行正确率、性能、证据可信能力与
稳定性四个维度的全量测试：

1. 知识库构建（500 份监管文件入库）的耗时与成功率；
2. 官方 300 题（选择题）正确率与处理时间；
3. 自命题 200 题（开放问答）正确率、证据引用命中率、拒答率、实体错误率与
   处理时间（CPU / GPU 两种环境）；
4. 并发稳定性。

### 1.2 我们自制了 200 题开放问答题

官方 300 题为**选择题**（选项比对即可判定），主要验证检索与识别能力，但**无法完全展示系统的真实能力**：选择题不需要系统自主组织答案、无法考察答案表述中的数字/日期/机构/文号准确性、证据引用是否真实命中来源文件、依据不足时是否诚实拒答等开放问答关键能力。

因此，我们依据银行业真实业务场景（信贷审批、风险分类、资本管理、消保投诉、反洗钱、支付结算、普惠金融、监管报送等）自命题 **200 道开放问答题**，覆盖八类题型——制度定义、规则/适用范围、金额阈值、名单类、表格取数、表格计算、跨文件场景判断、依据不足拒答——并编写金标（标准答案）与**确定性评分器**（无 LLM 判定，金标结论与答案逐条比对），用于测试系统的开放问答能力。

### 1.3 测试结论摘要

| 指标 | 赛题要求 | 实测结果 |
|---|---:|---:|
| 官方 300 题（选择题）准确率 | — | **300/300（100%）**，0 错误 |
| 制度事实类准确率（自命题 200 题） | ≥85% | **89.3%（CPU）** |
| 表格取数类准确率 | ≥80% | **100%（40/40）** |
| 证据引用命中率 | ≥90% | **91.3%（CPU）/ 91.9%（GPU）** |
| 关键数字/日期/机构/文号错误率 | ≤5% | **2.4%** |
| 拒答/澄清率（依据不足题） | ≥80% | **100%（40/40）** |
| 自命题 200 题总准确率 | — | **183/200 = 91.5%（CPU）** |

## 2. 测试环境

| 项目 | 配置 |
|---|---|
| CPU | AMD Ryzen 9 8945HX（16 核/32 线程），内存约 34 GB |
| GPU | NVIDIA GeForce RTX 5070 Laptop，8 GB 显存（CUDA 可用） |
| 运行方式 | Docker 容器 `regumate/app:contest-v3`（build_id `regumate-agent-small`），torch 2.11.0+cu128 |
| 模型 | BGE-M3（embedding，本地）+ BGE-reranker-v2-m3（重排，本地）+ DeepSeek API（deepseek-v4-flash，生成/规划/校验） |
| 知识库 | 官方 500 份监管制度与统计附件（doc 32 / docx 34 / pdf 45 / xls 232 / xlsx 157） |
| 向量索引 | Qdrant，45,530 条向量（稠密+稀疏混合检索） |
| 结构化索引 | SQLite，46,551 chunk + 133,001 表格单元格（坐标/行/列标签/单位/数值） |
| CPU 模式 | 容器无 CUDA 时按 `MODEL_DEVICE=cuda` 请求自动回退 `cpu_balanced`（16 线程） |
| GPU 模式 | `--gpus all` 启动，`selected_device=cuda`，`performance_mode=gpu` |

> 官方 300 题与自命题 200 题在 CPU、GPU 两种环境下各完整跑测一轮，
> 串行执行、0 运行错误，保证逐题延迟测量纯净。

## 4. 官方 300 题测试（选择题）

官方题集：`data/contest_dataset/QA数据.xlsx`（300 题，Excel/Word/PDF 各 100，
覆盖表格取数、表格计算、表格比较、单/多事实检索等题型，含证据与来源字段）。

### 4.1 正确率

**300/300 = 100%，0 运行错误**——本次 CPU、GPU 两轮实测均为 300/300，
与开发期间 10+ 次回归结果一致（每次生产改动后回归，始终 300/300）。

### 4.2 处理时间（单轮问答，串行）

| 环境 | 平均 | P50 | P95 | 最大 |
|---|---:|---:|---:|---:|
| **CPU**（2026-08-05 实测） | 7.03 s | 0.26 s | 32.2 s | 64.2 s |
| **GPU**（2026-08-05 实测） | **0.54 s** | 0.22 s | 3.51 s | 8.66 s |

> 选择题大部分为确定性表格链路（Excel 类 P50 ~0.2 s，CPU/GPU 几乎无差）；
> 文本类含 LLM 生成，GPU 平均提速约 13 倍（7.03 → 0.54 s）。

## 5. 自命题 200 题测试（开放问答）

题集：旧批 100 题（`去锚100题`）+ 新批 100 题（`去锚100题B`），八类题型：
制度定义、规则/适用范围、金额阈值、名单类、表格取数、表格计算、跨文件场景
判断、依据不足拒答。金标与确定性评分器随包交付
（`data/evaluation/自命题200题评测集/`）。

### 5.1 正确率

| 批次 | CPU（2026-08-05 最终验收） | GPU（2026-08-05 实测） |
|---|---:|---:|
| 旧批 100 题 | 90/100 | 88/100 |
| 新批 100 题 | 93/100 | 92/100 |
| **合计** | **183/200 = 91.5%** | **180/200 = 90.0%** |

> 两轮均 0 运行错误。GPU 与 CPU 差 3 题，处于同代码重复运行已记录的
> LLM 生成波动区间（±1–3 题），非设备差异；表格类 40/40、拒答 40/40
> 两轮完全一致。

### 5.2 分类型准确率（合计 200 题）

|---|---:|---:|

| 制度定义 | 29/30 | 27/30 |

|---|---|---|---|

| 引用返回率（回答必带引用） | — | 100% | 100% |

| 拒答/澄清率 | ≥80% | **100%（40/40）** | 100%（40/40） |

### 5.4 处理时间（单轮问答，串行）

> 偶发慢响应（CPU/GPU 均存在），非本地计算瓶颈。拒答类与表格类确定性链路
> 毫秒级返回（~10–70 ms）。

## 7. 结论

1. 官方 300 题选择题 **300/300（100%）**，0 错误；
2. 自命题 200 题开放问答 **183/200（91.5%，CPU）/ 180/200（90.0%，GPU）**，
   0 运行错误——官方选择题之外，系统在开放问答（自主组织答案、证据引用、
   诚实拒答）上同样具备高准确率与可信性；
3. 赛题五项量化指标全部达标：制度事实类 89.3%、表格取数类 100%、证据引用
   命中率 91.3–91.9%、实体错误率 2.4%、拒答率 100%；
4. 性能：官方 300 题 GPU 平均 0.54 s；开放 200 题 GPU 平均 17.9 s（CPU
   28.4 s），满足比赛平台交互要求（确定性表格题毫秒级返回）；
5. 知识库 500 份文件 100% 入库（约 34 分钟一次性流程），证据支持条款级/
   段落级/表格单元级三种粒度返回。
